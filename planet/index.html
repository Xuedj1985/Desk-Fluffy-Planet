糖绒星球 · 说明

它是什么

一块铺在 Windows 桌面层上的收藏盒：壁纸之上、所有应用之下，不抢焦点，空白处点击穿透给真实桌面。被应用窗口盖住是正常的，按 Win+D 或最小化就能看见。

桌面的东西去哪了

未收纳的文件会散落在地毯上，用的是系统给的真实图标。拖到书架某一层＝真正移动到桌面上的「糖绒星球书架」文件夹（不是 AppData 深处）；书脊拖出书架＝还原到桌面；拖进糖果罐＝走系统回收站，可恢复。退出 App 时书架会就地解散，文件自动回到桌面原位，下次启动再收回来——即使不再打开这个 App，文件也始终躺在桌面上。

怎么玩

  • 拖动资料卡到书架：单张收纳；打开「点选模式」可点选多张后整组上架。
  • 书脊在书架内拖动＝换层 / 排序；拖出书架＝还原；点一下＝打开文件。
  • 相册：点空拍立得选图，或把图片拖进去；右键换图 / 清空。相册存的是快照，原图被收进书架也不会碎。
  • 展柜：点玩偶上传 PNG / GIF（单张 ≤ 5MB，GIF 动效原样保留）；按住拖动可自由摆放，松手记住位置；鼠标滚轮放大 / 缩小这一只（50%–200%），右键可调前后层级（置于最前 / 最后）；顶部 ‹ › 调整倾斜度（±30°）；双击系列标签可改名。
  • 便签：点开可写多行，Ctrl+Enter 保存；点 × 撕掉后可撤销；把便签拖进糖果罐会归档成 Markdown。
  • 唱片机：选一个装 MP3 的文件夹；三种模式（列表循环 / 播完即停 / 单曲循环）写进配置，重启保留。
  • 我的电脑：磁盘与内存是真实读数，点一下有 6 个快捷入口，双击进屏保。
  • 画面适配：托盘图标右键 →「画面适配」，可选自动 / 1920×1080 / 2560×1440 / 2880×1620 / 3120×2080。画面会在底部自动留出任务栏安全间距。
  • 开机自启动：托盘图标右键 → 勾选「开机自启动」。

数据放哪

%APPDATA%\xome-planet\：layout.json（便签与落点）、shelf.json + shelf\（收纳条目与原件）、frames.json + frames\（相册快照）、showcase.json + figures\（展柜形象）、audio.json、journal.jsonl（移动日志）。别删 shelf\，那是被收纳的原件。
