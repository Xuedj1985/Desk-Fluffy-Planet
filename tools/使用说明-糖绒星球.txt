糖绒星球 1.0.0 — Windows 桌面层主题（绿色免安装版）

【系统要求】Windows 10 / 11（64 位）。无需安装 .NET、无需运行库、不需要管理员权限。

【字体】界面已内置开源字体：英文 Allo、中文猫啃网糖圆体（均为 SIL Open Font License 1.1，许可文件在 assets/fonts/ 下）。

【交付 / 安装】把整个「糖绒星球」文件夹复制到任意位置（桌面、D 盘、U 盘都行），
双击里面的「糖绒星球.exe」即可。没有安装过程，也不写注册表（只有可选的「开机自启动」会写一条登录项）。
想放桌面图标：双击「创建桌面快捷方式.bat」。

【首次启动被拦】程序没有做代码签名，Windows SmartScreen 可能提示「未知发布者」：
点「更多信息」→「仍要运行」即可。这是绿色软件的正常现象。

【启动】双击桌面上的「糖绒星球」快捷方式，或双击 糖绒星球.exe。没有安装过程，不需要管理员权限。

【看不到是正常的】
糖绒星球是铺在壁纸之上、所有应用窗口之下的一层玻璃柜：不抢焦点，空白处的点击会交还给真实桌面。整窗铺了一层粉紫渐变底（概念稿的三色底），桌面壁纸不会透进来；柜体本身是一块接近不透明的粉色玻璃。桌面图标会被主题盖住，原来的位置仍然可点；空白处的点击仍交还桌面。
被应用窗口盖住是正常的，按 Win+D（显示桌面）或最小化窗口才露出来。

【退出】
1. 托盘粉色小星星图标 → 右键 → 退出
   （Win11 默认把它收进「^」溢出区，第一次拖到可见区域）
2. 顶栏右侧的 ×
3. 星球里按 Ctrl+Q
4. 双击 退出.bat（找不到托盘时的兜底）

【地毯上的资料】
桌面上还没收纳的文件会散落在地毯上，用的是系统给的真实图标，歪斜角度随机；卡片底色按格式给浅彩（和书架书脊同一套配色），右上角小角标与左侧立边是原格式色。
拖到书架某一层 = 真正移动：原件离开桌面，进「桌面\糖绒星球书架」目录，书架上出现书脊。
退出 App 时书架会就地解散、文件自动回到桌面原位；下次启动再收回——即使以后不再打开这个 App，文件也始终躺在桌面上。
书脊在书架里拖 = 换层 / 排序，松手吸附固定，位置会记住。
书脊拖出书架 = 还原到桌面；拖进糖果罐 = 走系统回收站，可恢复。
资料 = 彩色书本，所有书脊一样高（66px），竖排写书名前六个字；不同格式起笔齐平，数字也正立，全名鼠标悬停可看。底色是浅化后的格式色（两侧仍留原色立边，按格式区分照旧），书脊文字统一深墨粗字，和文件夹一样醒目。
文件夹 = 暖牛皮色书脊，和资料一样竖排名字前四个字（如「海边照片」），没有正面标签，也不再显示子项数。
文件夹快捷方式 = 蓝灰书脊，侧面竖排名字前四个字，右上角有折角；只靠颜色区分两种文件夹，全名鼠标悬停可看。
点一下资料卡在「点选模式」下可多选，顶部胶囊可整组上架。
按住 Alt 在地毯空白处拖动 = 框选。

【底部应用坞】
桌面上的 .lnk / .url / .exe 应用快捷方式会自动收进最下面一排「桌面应用」，不再散在地毯上；文件夹快捷方式仍在地毯/书架。
点图标 = 打开；按住拖动 = 换位置或换栏；右键 = 打开 / 资源管理器定位 / 移到第 1 栏、第 2 栏、第 3 栏。
分栏不显示名称，每栏只是一条虚线空槽，想把哪个应用放哪一栏都随你；槽里不再写提示小字，拖进去时整栏会高亮。
默认就是 3 栏、铺满整宽；新应用会自动放进当前最空的一栏。要切换分栏，右键任意应用图标 →「改为 2 栏 / 改为 3 栏」。布局存在 %APPDATA%\xome-planet\layout.json 的 dock 里，重启不丢。
为给这一排留位置，展柜压矮了一些（宽度不变），地毯、今日小愿望和唱片机都上移了，不会被应用坞挡住；书架也补回了整圈的白色圆角外框。

【展柜】
中间玻璃柜默认站 5 只「糖绒小精灵」占位形象。
点玩偶 = 选一张 PNG / GIF 放进去（单张 ≤ 5MB，GIF 动效原样保留）。
按住玩偶拖动 = 在玻璃柜里自由摆放；松手记住位置，重启不跳；拖到前排会自动变大、压到上层。
鼠标滚轮 = 放大 / 缩小这一只（50%–200%），标签上会显示百分比；后排玩偶不会自动变暗。
右键玩偶：上传 / 移除 / 往前一层 / 往后一层 / 置于最前 / 置于最后 / 这一位回到默认站位 / 全部重排 / 与下一位交换形象。
顶栏「重排」= 所有玩偶回到当前系列的默认站位；‹ › = 交换形象。
双击系列标签（37cm 大号 / 焦糖 / 星星人 / 自定义）= 改名，最多 8 个字；右键可恢复默认名称。
四套系列主题只换灯光、配色；已上传的形象和自由摆位一律保留，想用新系列的默认站位点「重排」。
最多站 6 只、最少 1 只（这是柜子容量，不是系列清单）。

【甜甜相册】
四张拍立得默认全空。点空相册 = 从电脑选一张；把图片拖进去也可以。
右键 = 换一张 / 打开大图 / 打开原图位置 / 清空。
相册存的是快照副本，所以原图被收进书架、改名或删除后，相册仍然显示。

【今日小愿望】
点便签正文可写多行，Ctrl+Enter 保存。
做完了点右上角 × 撕掉，底部会弹出「撤销」，误删可以立刻找回。
把便签拖进糖果罐 = 存成文本归档（%APPDATA%\xome-planet\notes-archive.md），不是直接消失。

【糖霜唱片机】
选文件夹 → 自动列出该目录顶层的 MP3。
模式按钮循环切换：列表循环 / 播完即停 / 单曲循环，切换后会记住。
没选 MP3 时点播放会跑一段演示旋律（唱片会转，能出声）。

【我的电脑】
左上正方形屏显示真实的磁盘 C: 与内存占用率，以及当前时间。
点一下弹出 6 个快捷入口（个人文件夹 / 桌面 / 文档 / 下载 / 图片 / 回收站），直接打开。
双击进屏保，再双击回来。

【收纳记录】
Ctrl+J 或点顶栏「收纳记录」：每次移动都有一行日志，可一键还原全部、打开收纳目录、查看便签归档。

【画面适配与任务栏】
托盘粉色星星图标 → 右键 →「画面适配」：
  自动（跟随窗口）/ 1920×1080 / 2560×1440 / 2880×1620 / 3120×2080
档位是「参考分辨率」：屏幕比档位小时会按最大可用比例显示，不会溢出。
16:9 屏幕会把中间展柜横向展开，柜体尽量铺满宽度；3:2 / 竖屏保持 1440 基准。
切换后立刻生效，并记在 %APPDATA%\xome-planet\display.json。
窗口本身铺在任务栏之外的工作区上；画面底部还会再留 24–56px 安全间距，
自动隐藏任务栏弹出来时也不会压住糖果罐和底部提示条。

【数据位置】
%APPDATA%\xome-planet\
  layout.json     便签内容与地毯落点
  shelf.json      书架清单
  journal.jsonl   每一次移动的日志（intent / done 成对）
  shelf\          被收纳的原件 —— 不要删
（糖绒星球的书架原件实际放在「桌面\糖绒星球书架」，退出 App 时自动散回桌面）
  frames.json     相册每格放了哪张快照
  frames\         相册的图片快照副本
  showcase.json   展柜的系列、站位数与形象文件名
  figures\        展柜里的形象原图
  audio.json      唱片机的目录与播放模式
  display.json    画面适配档位（自动 / 1920×1080 / …）
  notes-archive.md 从糖果罐归档的便签文本

【卸载】
退出后删掉整个文件夹即可。
正常退出时书架会自动解散回桌面，不会丢文件；如果 App 被强杀，文件仍在「桌面\糖绒星球书架」里，直接打开即可取回。
