## 怎么读

1. 先读对应文档的 **§0 文档定位**、**§2.3 目录结构**、**§6 风险**。
2. **§7 编码风格与偏好约定两份完全相同**，且是写任何代码 / 规则 / 文档之前的必读项。
3. 跑 **附录 A** 的命令速查，确认回归基线全绿。
4. 按 **§5.3 后续待办** 的优先级推进，按 **§8 交接检查清单** 收尾。
5. 想先看「这次补了什么」，直接读 03 的 **附录 D**。
